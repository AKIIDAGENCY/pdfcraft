# غرفة التحقيق (Investigation Room)

برنامج سطح مكتب لنظام **ويندوز** يساعد المحقق على تنظيم ملفات القضايا التي تضم عددًا كبيرًا من المتهمين، بحيث لا يُنسى أي إجراء بحق أي متهم.

هذا مشروع مستقل قائم بذاته داخل هذا المستودع (غير مرتبط بأدوات PDFCraft)، مبني بلغة C# على منصة .NET 8 وواجهة Avalonia UI.

## الفكرة

- تُنشئ **ملف قضية** واحدًا أو أكثر.
- تضيف داخل كل ملف قائمة **المتهمين**.
- لكل متهم قائمة **إجراءات** خاصة به (استجواب، مذكرة إحضار، إيداع، تقرير خبرة... إلخ) — أنت من يحدد أسماءها، لا توجد قائمة جاهزة مفروضة.
- تبني **قائمة إجراءات افتراضية** مرة واحدة من زر "إدارة القائمة"، فتُطبَّق تلقائيًا على كل متهم جديد تضيفه (وتظل قابلة للتعديل لكل متهم على حدة).
- تبويب **"المتابعة"** يجمع كل الإجراءات غير المُنجزة من كل الملفات والمتهمين في قائمة واحدة مرتّبة، مع تمييز الإجراءات التي تجاوزت تاريخ استحقاقها باللون الأحمر — فلا يضيع إجراء بحق أي متهم مهما كثر عددهم.
- **حفظ تلقائي** بعد كل تعديل، بدون الحاجة لأي زر "حفظ". تُخزَّن البيانات محليًا على جهازك فقط (لا اتصال إنترنت ولا خوادم خارجية).

## التشغيل السريع (Windows)

انسخ ملف `InvestigationRoom.exe` الجاهز إلى جهاز ويندوز وشغّله مباشرة بالنقر المزدوج — لا يحتاج تثبيت .NET أو أي برنامج آخر (ملف تنفيذي مستقل self-contained).

تُخزَّن بياناتك في:
```
%AppData%\InvestigationRoom\workspace.json
```
يمكنك نسخ هذا الملف احتياطيًا أو نقله إلى جهاز آخر ليحمل معه كل قضاياك.

## البناء من المصدر

يتطلب [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
cd investigation-room/src/InvestigationRoom

# تشغيل مباشر أثناء التطوير (يعمل على ويندوز/لينكس/ماك)
dotnet run

# بناء ملف exe واحد مستقل لويندوز (يمكن تنفيذه من لينكس أيضًا بفضل نشر .NET المتعدد المنصات)
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:DebugType=none -p:EnableCompressionInSingleFile=true \
  -o ../../publish/win-x64
```

الناتج: `investigation-room/publish/win-x64/InvestigationRoom.exe`.

## هيكل المشروع

```
investigation-room/
  src/InvestigationRoom/
    Models/        - نماذج البيانات (ملف قضية، متهم، إجراء)
    ViewModels/     - منطق الواجهة وربط البيانات (CommunityToolkit.Mvvm)
    Views/          - نوافذ الواجهة (Avalonia XAML)
    Services/       - حفظ وتحميل البيانات (JSON محلي)
    Converters/     - محوّلات عرض (حالة الإجراء، تجاوز الموعد...)
```

## ملاحظات

- الواجهة بالكامل باللغة العربية ومن اليمين إلى اليسار (RTL).
- لا تتضمن أي قائمة إجراءات جاهزة مسبقًا عمدًا — أنت من يبني القائمة التي تناسب طبيعة عملك وإجراءاتك المتّبعة.
- حذف ملف قضية أو متهم أو إجراء يطلب تأكيدًا صريحًا لتفادي فقدان البيانات بالخطأ.
